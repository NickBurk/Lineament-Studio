# Performance Requirements

## Standard Profile
Целевой профиль: 16 ГБ RAM; CPU; integrated graphics; GPU не обязательна.
Worker memory budget 6 ГБ и tile 1024×1024 — стартовые значения для измерения, не обещанные
гарантии. Точные целевые метрики фиксируются после benchmark.

## Tile processing
Начальный tile size: 1024×1024 пикселя, настраиваемый. Halo зависит от радиуса фильтров
и алгоритмов. Для каждого tile задаётся центральная область ответственности.

## Cache
Ограниченный, очищаемый, восстанавливаемый; не является единственным местом хранения результата.

## Parallelism
Последовательная обработка — default. Параллельность включается только после оценки RAM
и свободного места. UI остаётся отзывчивым.

## Benchmark sizes
1k×1k; 5k×5k; 10k×10k; 20k×20k; мозаика из нескольких DEM.
Фиксируются время, peak RAM, CPU, временный диск, размер результата и ошибки.

## Отмена и recovery
Отмена между безопасными блоками. Завершённые блоки повторно используются только при совпадении
checksums и параметров. Неполные результаты не регистрируются как финальные.
