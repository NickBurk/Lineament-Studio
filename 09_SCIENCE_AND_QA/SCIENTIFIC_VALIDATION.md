# Scientific Validation

## Четыре уровня
1. Technical Validation — вычисления, CRS, геометрия, NoData.
2. Algorithm Validation — поведение и устойчивость детекторов.
3. Expert Validation — сравнение с независимой разметкой.
4. Geological Validation — независимые геологические/полевые свидетельства.

## Разделение утверждений
Наблюдаемые признаки; вычисленные метрики; интерпретационные гипотезы; геологические выводы —
разные уровни. Альтернативные причины линейной формы включают литологию, эрозию, дренаж,
антропогенные объекты, артефакты DEM, особенности визуализации и другие процессы.
Для проверки могут потребоваться геологические карты, полевые наблюдения, геофизика,
снимки и структурные измерения.

## Метрики
Precision; Recall; F1; IoU для растровых масок; Hausdorff Distance; Chamfer Distance;
length-weighted recall; expert agreement. Для векторных линий фиксируется spatial tolerance
и проводится анализ чувствительности к нему.

## Численная корректность
Для каждого научного метода документируются формула/псевдокод, источники или статус основания,
входы/выходы, единицы, диапазоны, допущения, NoData/NaN/Inf, dtype, граничные случаи,
численная tolerance, сложность и память.

## Аналитические fixtures
Плоскость с известным уклоном; синусоидальная поверхность; константа; импульс; ступень;
NoData mask; границы тайлов; разные resolution; разные dtype/scale. Проверяются ожидаемые
значения, средняя/максимальная ошибка, локальные артефакты, инварианты и чувствительность.

## Ограничения
Stability не равна geological confidence. Detector Agreement не равен независимому доказательству.
LSM не равна вероятности разлома. Совпадение с картой не обязательно независимо, если карта
использовалась при настройке. Отсутствие линии не доказывает отсутствие структуры.

## Reproducibility
Каждый эксперимент сохраняет DEM checksum, версии алгоритмов/зависимостей, параметры, CRS,
units, software versions, seed, outputs и checksums.
