# UI/UX Specification

## Общая концепция
Профессиональный, лаконичный интерфейс исследовательского GIS-приложения. Основной экран —
карта и контекстные инструменты. Не перегружать интерфейс всеми параметрами одновременно.

## Главное окно
- верхняя панель проекта и команд;
- левая навигация по рабочим пространствам;
- центральная карта/рабочая область;
- правая контекстная панель;
- нижняя панель задач, логов и предупреждений.

## Принципы
- рабочая карта/растр имеет приоритет над декоративными панелями;
- простые настройки видны сразу, расширенные раскрываются по запросу;
- частые действия заметны и предсказуемы;
- технические имена переменных не показываются вместо пользовательских терминов;
- CRS, единицы, NoData и ограничения видны, когда влияют на результат;
- опасные/разрушающие операции требуют подтверждения;
- длительные задания показывают реальный прогресс, этап, отмену и завершение;
- Overlay — основной режим сравнения геологических карт; Swipe и Side-by-side — дополнительные.

## Обязательные состояния
Каждый экран и операция определяют применимые состояния:
`empty`, `loading`, `ready`, `running`, `success`, `warning`, `error`, `disabled`.
Пустое состояние нового проекта и повторное открытие проекта/DEM проектируются явно.

## Доступность и ввод
Keyboard navigation; понятный focus order; shortcut hints; контраст; масштабирование интерфейса;
подписи/подсказки для неоднозначных иконок. Цвет не является единственным носителем статуса.

## Справка параметров
Каждый параметр имеет назначение, единицы, диапазон, default, validation, влияние увеличения/
уменьшения, взаимодействия, предупреждения, графический мини-пример и ссылку на научное описание.

## Окно помощи
Parameter Help Window или side panel открывается из конкретного параметра.
