# Workspaces

## Dashboard
Сводка проекта, источники, последние эксперименты, предупреждения, быстрые действия.

## Data Workspace
Слои, DEM Preflight, источники, CRS, геологические карты, OSM.

## Detection Studio
Single/Ensemble, detector profile, Preview Grid, параметры и оценка ресурсов.

## LSM Explorer
Карта LSM, карты компонентов, disagreement, профиль поддержки кандидата.

## Structural Analysis
Роза направлений, кластеры, плотность, узлы, статистика и ранжирование.

## Review Studio
Очередь кандидатов, карта, атрибуты, сравнение с геологическими картами, экспертные статусы.

## Dataset Studio
Выбор Annotation Set, chips/masks, split, проверка классов, экспорт.

## Smart Workflow
Tuning, Labeling, QA. Компактная панель действий, не полноэкранный чат.

## Reports
Map Composer, графики, таблицы, параметры эксперимента, экспорт.

## Settings
Профили ресурсов, пути, язык, кеш, Runtime, лицензии, диагностика.
