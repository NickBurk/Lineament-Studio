# Parameter Guide Requirements

## Карточка параметра
1. Название и стабильный `parameter_id`.
2. Простое словесное объяснение.
3. Что меняет параметр.
4. Единицы.
5. Допустимый диапазон.
6. Значение по умолчанию.
7. Рекомендуемый стартовый диапазон.
8. Эффект увеличения.
9. Эффект уменьшения.
10. Взаимодействия.
11. Предупреждения.
12. Графический пример.

## Графический пример
Для параметров детекции показывать один и тот же фрагмент DEM/Hillshade с несколькими значениями. Extent, масштаб и контраст должны совпадать. Иначе сравнение вводит в заблуждение.

## Примеры
- Canny thresholds — изменение числа и связности границ.
- LoG sigma — изменение масштаба деталей.
- Minimum line length — удаляемые короткие сегменты.
- Merge distance — риск чрезмерного объединения.
- LSM radius — ширина зоны пространственной поддержки.

Иллюстрации должны быть обозначены как демонстрационные, если это не результат текущего проекта.
