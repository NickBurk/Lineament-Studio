# AI Co-pilot

## UX
Одна компактная панель с действиями: «Подобрать параметры», «Разметить очередь», «Проверить ансамбль». Полноэкранный чат не является основным интерфейсом.

## Безопасность
Read-only анализ по умолчанию; изменения только через зарегистрированные операции; подтверждение массовых изменений; preview результата; undo/rollback, где поддерживается; журнал действий.

## Внешние LLM
Опциональны. До отправки данных пользователь видит, какие сведения передаются. Исходные DEM, геологические карты и экспертная разметка не отправляются без явного согласия.

## Offline fallback
При отсутствии сети/API базовые Tuning, Labeling и QA работают в rule-based режиме.
