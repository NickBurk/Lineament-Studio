# Smart Workflow

## Уровни
1. Rule-based Intelligence — полностью offline.
2. Local Classical ML — CPU, без обязательной GPU.
3. Optional AI Services — внешние API только по явному включению.

## Tuning Agent
Анализирует DEM и параметры; выбирает Preview Window; запускает ограниченный Preview Grid; рассчитывает эвристические метрики; выдаёт до трёх компромиссных конфигураций; объясняет различия. Без Ground Truth не объявляет вариант научно правильным.

## Labeling Agent
Ранжирует Pending кандидатов, показывает причины приоритета, использует расхождения/нестабильность/ML uncertainty. Не принимает и не отклоняет без подтверждения человека.

## QA Agent
Ищет дубликаты, аномальную геометрию, артефакты границ тайлов, ошибки CRS/provenance и несогласованность прогонов. Предлагает исправления.

## Исполнение
Агенты вызывают только зарегистрированные Core operations с валидированными параметрами. Нет произвольного доступа к файловой системе и запуска произвольного кода.

## Логи
Каждое действие имеет job_id, actor, input references, suggested action, user approval, output references, timestamp.
