# OSM Integration

## Режимы
Online query через доступный сервис; offline import из PBF; импорт GeoPackage/GeoJSON.

## Категории
roads; railways; buildings; waterways/linear infrastructure при релевантности; power lines; пользовательские категории.

## Использование
OSM — контекстный слой для интерпретации и QA. Совпадение кандидата с дорогой или сооружением не является автоматическим основанием для удаления. Фильтр должен быть объяснимым и обратимым.

## Метаданные
Дата загрузки, источник, запрос/фильтр, версия локального файла и условия лицензии/атрибуции, если доступны.

## Ограничения
Соблюдать условия выбранного сервиса, rate limits и атрибуцию OpenStreetMap. Не использовать публичный endpoint для массовой загрузки без проверки его политики.
