# Independent Annotation

## Модель
Каждый эксперт работает в собственном Annotation Set. Наборы не перезаписывают друг друга.
Realtime co-editing не входит в обязательный scope v1.

## Поля Annotation
`annotation_id`; `candidate_id`; `annotation_set_id`; `reviewer_id`; `status`; `feature_type`;
`expert_confidence` (optional, 1–5); `notes`; `geometry_version`; `created_at`; `modified_at`.

## Импорт и сопоставление
- Каждый набор имеет устойчивый ID, автора, дату/версию, provenance и schema version.
- Импорт не перезаписывает набор по совпадению имени.
- Сопоставление учитывает версии схем, словари классов и геометрию.
- Согласие по геометрии отделяется от согласия по геологической интерпретации.
- Отсутствие метки не трактуется как отрицательная метка.

## Геометрия
Исходная геометрия кандидата сохраняется. Изменённая геометрия создаёт новую версию с автором,
временем и причиной изменения.

## Consensus
Consensus Set — отдельный производный набор. Исходные Annotation Sets остаются неизменными.
Конфликт не исчезает без записи решения; объединение требует preview и подтверждения.
