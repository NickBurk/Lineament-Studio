# AI Agent Task Template

## Task ID / Phase
`TASK-XXX` / `PHASE-XX`

## Requirement IDs
Перечислить связанные FR/NFR IDs и приоритеты.

## Required Skills
Точные `.agents/skills/<skill-name>/SKILL.md`; не подключать нерелевантные роли.

## Goal
Одно проверяемое предложение.

## Context
Профильные документы, ADR, существующие модули, baseline commit.

## Scope / Out of Scope
Что агент реализует и что не меняет.

## Owned Files
Каталоги и файлы, которыми агент может управлять; запретные зоны.

## Inputs / Outputs
Типы, форматы, единицы, CRS, schema и provenance.

## API Contract
Сигнатуры, JSON schema, JSONL events или модели данных.

## Acceptance Criteria
Given / When / Then для каждого основного сценария.

## Tests
Unit, integration, regression, scientific, GUI, performance, security или packaging по риску.

## Constraints
Не добавлять обязательные API; не использовать заглушки; не менять чужие контракты;
сохранять backward compatibility либо описать migration plan.

## Deliverables
Код, тесты, документация, QA report, список файлов, branch/commit reference.

## Completion Report
Изменённые файлы; команды; результаты; evidence; ограничения; известные дефекты; follow-up tasks.
