# Desktop Architecture

## Технологии
PySide6/Qt; собственный Qt Map Canvas; GDAL/Rasterio; PyProj; Shapely; SQLite/RTree;
отдельный Core Worker.

## Главное окно
- верхняя панель проекта и команд;
- левая навигация по рабочим пространствам;
- центральная карта/рабочая область;
- правая контекстная панель;
- нижняя панель задач, логов и предупреждений.

Панели сворачиваются и настраиваются. Основное пространство — карта.

## Карта
GeoTIFF, GeoPackage, векторные слои, прозрачность, порядок слоёв, Overlay, Swipe, Side-by-side,
выбор и базовое редактирование геометрии.

## Lifecycle и потоки
Длительные вычисления не выполняются в GUI thread. GUI не обновляется из неподходящего потока.
При закрытии окна определяется политика для активных Worker jobs; потоки, процессы, GDAL datasets
и file handles закрываются детерминированно. Повторный запуск/отмена/повторное выполнение
не должны оставлять orphan jobs.

## Производительность
Оконное чтение растров, overviews, ограниченный кеш, пространственная индексация, ограничение
геометрий, передаваемых в отрисовку. Отдельно измеряется время открытия и повторного открытия DEM.

## Риск
Собственный Map Canvas — значимый объём разработки. До масштабирования UI сделать вертикальный
прототип: большой GeoTIFF + несколько GPKG + CRS transformation + overlay + swipe + выбор линии.
