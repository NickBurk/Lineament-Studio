# Multi-scale Analysis

## Базовая конфигурация
- S0 = 1× исходное разрешение;
- S1 = 2× размер пикселя;
- S2 = 4× размер пикселя.

Для DEM 30 м это 30/60/120 м; для DEM 1 м — 1/2/4 м.

## Правила
1. Перед downsampling применяется сглаживание/агрегация.
2. Метод ресэмплинга сохраняется.
3. Масштаб не является геологическим порядком.
4. Результаты приводятся к согласованной географической основе.
5. Сохраняется связь с исходным DEM.
6. Радиусы фильтров задаются с явными единицами.

## Выходы
Отдельные кандидатные слои по масштабам, Scale Persistence, статистика длины/плотности, сопоставление структур между масштабами. Пользователь может менять число уровней и коэффициенты.
