# Ranking System

## Три понятия
1. Geometric Rank — вычисляемый геометрический класс.
2. User-defined Ranking — пользовательская модель.
3. Geological Order — экспертная геологическая классификация.

Они не взаимозаменяемы.

## Стартовая Geometric Score

\[
GScore=0.7P_L+0.3P_S
\]

`P_L` — процентиль длины, `P_S` — процентиль straightness. Straightness:

\[
S=\\frac{D_{endpoints}}{L_{line}}
\]

Обе величины нормируются в [0,1]. Формула — стартовый профиль, не научно установленная модель.

## Классы
- G1 — верхняя треть;
- G2 — средняя треть;
- G3 — нижняя треть.

Квантили зависят от выборки. Для межрегионального сравнения нужен фиксированный профиль с абсолютными порогами или эталонной калибровкой. UI показывает метод классификации.

## User-defined Ranking
Пользователь выбирает признаки, нормализацию, веса, пороги и правила. Профиль имеет ID и версию. Результаты сохраняют ID профиля.

## Geological Order
Назначается экспертом или импортируется. Метаданные: scheme, assigned_by, evidence_source, expert_confidence (optional), notes, assigned_at. Автоматическое назначение порядка только по длине, стабильности или LSM запрещено.
