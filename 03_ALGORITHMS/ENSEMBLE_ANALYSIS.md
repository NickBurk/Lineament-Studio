# Ensemble Analysis

## Назначение
Объединять результаты разных освещений, масштабов и семейств детекторов, оценивая устойчивость обнаружения и пространственную поддержку.

## Режимы
- `SINGLE` — один конфиг, диагностика и калибровка.
- `ENSEMBLE` — набор прогонов, сопоставление и агрегация.

## Стандартный стартовый профиль
8 азимутов: 0°, 45°, 90°, 135°, 180°, 225°, 270°, 315°; одна высота освещения по умолчанию 45°; три масштаба 1×, 2×, 4×; всего 24 hillshade-scale конфигурации. Дополнительные высоты и детекторы увеличивают число прогонов. До запуска пользователь видит оценку задач, времени, RAM и временного диска.

## Matching
Начальные значения: angular tolerance 15°; distance tolerance 2.5 пикселя исходного DEM; minimum overlap 50%. Это инженерные стартовые параметры, не геологические константы. Порог в метрах и пикселях должен быть различим.

Для осевой ориентации направления сравниваются modulo 180°. Сопоставление использует угловое отличие, расстояние и перекрытие.

## Кластеризация
Запрещено неконтролируемое chain-merging: цепочка близких сегментов не должна соединять две удалённые структуры. Проверять согласованность с представителем/модельной геометрией и общий угловой разброс.

## Выходы
Объединённые кандидаты; происхождение по прогонам; stability; detector_agreement; scale_persistence; таблица соответствий; предупреждения о неоднозначном matching.

## K/N
Знаменатель включает только применимые и успешно завершённые прогоны. Ошибочные/отменённые прогоны не трактуются как отсутствие обнаружения.

## Ресурсы
Последовательная обработка — default. Параллельность ограничивается Resource Manager. Промежуточные результаты очищаются только по выбранному режиму хранения.
