## Historical and numerical contract

Historical validation is independent of executable support. Schema 1 supports
Hillshade 2.0.0 and 2.0.1 explicitly; unknown versions fail closed. Only 2.0.1
is executable. The historical ZIP fixture was generated by the unmodified source
at the exact base using Copy storage and a real int16 GeoTIFF. It includes empty
project directories. Reopen verifies stored metadata and output checksum without
recomputation. Existing records and published files are never upgraded in place.

Hillshade 2.0.1 omits constant band offset before Horn differencing, since
D(scale*raw+offset)=scale*D(raw). Masking and scale remain mandatory; metadata
retains the original offset. Analytical plane fixtures use scale 0.5/2 and offset
0/+1e20/-1e20, compare tile sizes 3/20, and bound max/mean absolute error at 6e-8
and relative error at 2e-7. This does not recover detail absent from input float
samples; overflow still fails explicitly. Gaussian stability is future gated work.

## Cancellation and notification contract

Chunked copy and checksum check cancellation before and after each 1 MiB read.
Preflight checks between windows. Raster operations check between tiles. Native
GDAL calls are not instantly interruptible. Final source verification precedes
last cancellation check; the SQLite transaction checks once more before commit.
The last successful gate linearizes entry to committing; later requests cannot
produce CANCELLED. Existing JobLifecycle COMMITTING/COMMIT_STARTED contracts
remain applicable; this storage adapter does not implement a production Worker.
If publication raises after intent commit, caller must reopen/recover and inspect
the result/receipt before retrying; an exception does not establish cancellation.
Callbacks are observers: ordinary exceptions produce fixed diagnostics without
exception text and do not request cancellation or alter publication. Process exit
and BaseException are not suppressed. Explicit cancellation uses its own predicate.
