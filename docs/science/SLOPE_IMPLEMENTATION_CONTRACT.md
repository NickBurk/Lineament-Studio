## Proposed CCR-005

Preserve the existing Project.register_result keyword interface for Hillshade callers. Add an optional keyword slope with normalized SlopeParameters and make light optional. Require exactly one of light or slope. Change the internal adapter tile default to None and resolve it after algorithm selection to Hillshade 512 or Slope 1024. An explicit positive integer tile overrides that method default. Slope provenance records resolved tile_size in parameters, including explicit overrides. Existing Hillshade provenance schema/parameter keys remain valid for historical records. New Hillshade records retain their existing parameter keys and record the resolved tile size as a GeoTIFF tag covered by output_checksum, preserving the established strict historical schema. Select a fixed internal algorithm specification with runner, version, parameter serializer and metadata validator. Both branches use the existing private source snapshot, cancellation boundaries, durable publication and recovery.

Provenance schema 1 admits a second explicit algorithm/version pair slope/1.0.0 with its own exact parameter keys. Parameters are exactly method=horn, vertical_metres_per_unit, output_unit=degree, mask_policy=all-nine-valid-internal and tile_size. The public conversion name is vertical_metres_per_unit. The optional explicit declaration name is vertical_unit in SlopeParameters. Validate finite positive conversion and known compatible source vertical units. Resolve vertical units from the source band first. A missing source unit requires a recognized explicit vertical_unit declaration. Reject unrecognized nonempty source units even when a declaration is supplied. Supported normalized names are m/metre/meter (factor 1), ft/foot (0.3048), and us survey foot (1200/3937). Reject a declaration conflicting with known source units and any factor inconsistent with the resolved unit. Whitespace and case normalize only for comparison. Preserve the source unit string, or the explicit declaration when the source is missing, in source.vertical_unit. Persist the resolved finite positive factor as parameters.vertical_metres_per_unit. Validate source.horizontal_metres_per_unit separately against the projected CRS. Reject missing/unknown vertical units with no declaration. Hillshade historical 2.0.0/2.0.1 validation and executable support remain independently checked. Unknown algorithms, versions and extra parameter keys fail. Slope output metadata has vertical_unit=degree and float32/nodata=-1/scale1/offset0 with preserved grid. The actual file must have an internal per-dataset validity mask and finite valid samples in [0,90]. The snapshot checksum covers mask and output bytes. Manifest 1.1 and SQLite 2 stay compatible. Public Wire messages remain unchanged.

Implement slope.py with an algorithm descriptor and Horn kernel. Reuse raster window, calibration and masked-read utilities. Share only the existing publication machinery. Preserve the established Hillshade numerical path. Slope defaults to 1024 core pixels per side with a one-cell halo. Hillshade retains its 512 default. Both honor explicit positive integer tile overrides. Set GDAL_TIFF_INTERNAL_MASK for the output creation context and write the binary mask for each window. Cancellation and progress use existing execution helpers.

p_raw increases right/column and q_raw increases down/row. Both divide weighted opposite-neighbor differences by 8. Multiply both by band scale and vertical metres/unit. Multiply the affine linear 2x2 matrix by horizontal metres/unit. With p_m=p_raw*scale*vertical_metres_per_unit, q_m=q_raw*scale*vertical_metres_per_unit and A_m=horizontal_metres_per_unit*A, compute g=A_m^(-T)[p_m,q_m]. Apply no second row-sign flip. Slope is degrees(atan(hypot(gx,gy))). Constant offset is excluded before derivatives. No exaggeration parameter exists.

## Test matrix before implementation

| Group | Evidence |
|---|---|
| Analytic planes | Flat and signed east/north/diagonal gradients, multiple steepnesses. Absolute error <=1e-5 degree in float32 interior. |
| Coordinates/units | Projected metre and US survey foot CRS, separate metre/foot vertical factors, anisotropic/rotated/skewed affine. Reject absent/geographic CRS, singular/nonfinite affine, unrecognized units and nonpositive factors. |
| Contract | Method defaults 512/1024, explicit tile override and persisted resolved size, unsupported tile types/values, known/missing/unknown vertical units, explicit declaration conflicts, unit-factor mismatch and provenance round-trip. |
| Calibration | Scaled integer versus physical float, large constant offset, independent scalar Horn oracle. |
| Validity | Nodata -1, input internal mask, NaN/Inf, each missing neighbor, border, rasters smaller than 3x3, all-invalid output surfaced in metadata. Exact internal output mask. |
| Tiling | 1024 halo1 versus full-array oracle, partial edge tile, several tile sizes and identical masks. |
| Execution | Cancellation during read/compute/prepublication, callback exceptions, no partial output publication. |
| Project | Reference/Copy import, immutable input digest, output registration, strict provenance malformed cases, fresh process reopen/recovery and historical Hillshade fixture. |
| Resources | Explicit working-set estimate and runtime/peak RSS/temp disk/cancel measurements on 1k/5k/10k/20k fixtures, recorded per actual execution. |
