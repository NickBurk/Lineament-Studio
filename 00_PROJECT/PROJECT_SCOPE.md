# Project Scope

## Входит
Desktop Bundle Windows; независимое Python-ядро; DEM Preflight/preprocessing; edge detection и line-segment extraction; Single/Ensemble; Multi-scale; LSM_DEM; геометрическое и пользовательское ранжирование; структурные направления, плотность и узлы; импорт геологических растров/векторов; OSM; Batch Processing; Review Studio; Independent Annotation; Dataset Builder; базовый классический ML; Smart Workflow без обязательной LLM; экспорт; отдельный QGIS plugin; GEE adapter.

## Не входит в обязательную базовую версию
Полноценная замена QGIS; встроенный georeferencing; обязательный анализ профилей рельефа; обязательная GPU; обязательный облачный AI API; обязательная локальная LLM; автоматическое подтверждение геологических разломов; совместная разметка в реальном времени; полный cloud detection backend в GEE.

## Версии
MVP должен быть полезен для реального DEM-исследования. Version 1.0 добавляет полноценную экспертную работу, датасеты, QGIS и отчётность. Расширенный GEE backend и Deep Learning — после стабилизации ядра.
