# Glossary

| Термин | Определение |
|---|---|
| DEM | Digital Elevation Model |
| Lineament | Линейная форма или морфологическое проявление, выделенное по данным |
| Candidate | Обнаруженный объект, ожидающий интерпретации |
| Detector | Алгоритм обнаружения границ или линейных сегментов |
| Detector Family | Семейство близких методов |
| Hillshade | Растровая визуализация освещённости рельефа |
| Multi-scale | Анализ на нескольких пространственных масштабах |
| Ensemble | Набор прогонов с разными конфигурациями |
| Stability | Устойчивость обнаружения между прогонами |
| Detector Agreement | Согласие семейств детекторов |
| Support Score | Вычислительная пространственная поддержка |
| LSM | Lineament Support Map |
| LSM_DEM | LSM только по DEM-свидетельствам |
| LSM_Fused | Расширенная карта с дополнительными источниками |
| Geometric Rank | Геометрический класс кандидата |
| Geological Order | Экспертная геологическая классификация |
| Annotation Set | Независимый набор экспертных решений |
| Consensus Set | Производный набор согласованных решений |
| Chip | Фрагмент растрового изображения для датасета |
| Halo | Перекрытие тайла для корректной обработки границ |
| Core Worker | Отдельный процесс вычислительного ядра |
| Preflight | Проверка входных данных до обработки |
| NoData | Значение отсутствующих данных |
| COG | Cloud Optimized GeoTIFF |
| CRS | Coordinate Reference System |
| OSM | OpenStreetMap |
| GEE | Google Earth Engine |
| IPC | Межпроцессное взаимодействие |
| DoD | Definition of Done |
